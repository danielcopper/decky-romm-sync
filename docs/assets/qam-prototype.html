Why everything about one platform in one place

  • Today there are three platform lists on three pages from three callables. Setting up a platform means Library, then System, then Data Management. Now one list and one detail.
  • "System" disappears as a page, and with it the question of what to call it.
  • Data Management becomes unambiguous: only what concerns the whole library.
  • Rejected: Library keeps only Sync, a page "Emulation" gets Core and BIOS, Data Management keeps the per-platform actions. It separates by topic but leaves three platform lists standing.

Why Sync is its own page

  • Main loses eight rows of sync controls and becomes status plus one button.
  • The preview gets the room for a table per platform (#886) and for the import choice (#1364).
  • Everything that concerns a sync run is in one place: preview, progress, history, Force Full Sync, the session budget with Restart Steam.

Flow

  • "Sync Library" on Main opens this page and computes the preview. Apply happens here.
  • If a valid preview is already waiting, the button on Main opens this page with exactly that one. It is computed again only through "Refresh" next to the preview, and discarded only through Cancel.
  • With "Skip preview" on, the sync runs straight away and Main shows the progress as today. This page shows it too, with fine detail and cancel.
